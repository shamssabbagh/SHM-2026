## 2. תיאור הפעולות שבוצעו וההחלטות ההנדסיות

### א. התאמת הממשק להצגה בפני קהל (Audience-First UX)
1. **שינוי כותרת השקופית:** 
   הכותרת עודכנה מ-`הדגמת קוד Python: סימולציית אפקט העיגון` לכותרת נגישה וממוקדת תוכן: **"אפקט העיגון: איך המחיר הראשון משפיע עלינו?"** בליווי תגית עליונה: `סימולציה אינטראקטיבית`.
2. **הסרת פרטים טכניים מהתצוגה:**
   * הוסרה תיבת קוד ה-Python (`py-code-snippet-box`) שהציגה את תחביר הפונקציה.
   * הוסר תג מספר גרסת ה-Python (`Python v3.11`).
   * הוסרו אזכורים טכניים פנימיים כגון "Pyodide WebAssembly" ופקודות הרצה מלוח התצוגה.
   * כותרת התוצאות עודכנה ל-**"📊 הערכת השווי של הצרכן:"** וכותרת המדד שונתה ל-**"הערכת שווי משוערת"**.
3. **החלפת תיבת הקוד בתובנה התנהגותית יישומית:**
   במקום קוד תוכנה, נוספה כרטיסיית תובנה צרכנית מעוצבת:
   > 💡 **תובנה התנהגותית:** המחיר הראשון שהצרכן פוגש משמש כעוגן תודעתי (Anchor). גם כאשר ידוע שהמחיר האמיתי הוא 399 ₪, חשיפה לעוגן גבוה ממסגרת את המוצר כיוקרתי ואיכותי יותר ומעלה את הערכת השווי הסובייקטיבית שלו.
4. **עדכון כפתור הפעולה:**
   הכפתור שונה מ-"הרץ חישוב ב-Python" ל-**"🎯 בדקו את השפעת המחיר"**, בליווי הסבר ידידותי שהתוצאות והגרף מתעדכנים בזמן אמת עם הזזת המחוון.

### ב. שמירה על חישוב Python אמיתי ברקע (Pyodide WebAssembly)
* החישוב המתמטי ממשיך להתבצע **ב-100% על גבי מנוע Python אמיתי בדפדפן** באמצעות Pyodide WebAssembly:
  ```python
  def calculate_anchoring(base_price, anchor_price):
      base = float(base_price)
      anchor = float(anchor_price)
      estimated_val = base + 0.3 * (anchor - base)
      difference = estimated_val - base
      pct_increase = (difference / base) * 100.0 if base > 0 else 0.0
      return {
          "estimated_value": round(estimated_val, 2),
          "difference": round(difference, 2),
          "pct_increase": round(pct_increase, 1),
          "anchor_price": round(anchor, 2),
          "base_price": round(base, 2),
          "python_version": sys.version.split()[0],
          "executed_by": "Pyodide CPython WebAssembly"
      }
  ```
* הנתונים מועברים ישירות מקוד ה-Python אל ממשק המשתמש (דרך ה-Proxy של Pyodide).

### ג. שקיפות ושליטה במקרה של תקלה (Failure Transparency)
1. **הודעת שגיאה פשוטה וברורה:** במידה וטעינת מנוע החישוב נכשלת (למשל עקב היעדר חיבור אינטרנט בפעם הראשונה), מוצגת הודעה נטולת שגיאות קוד מפחידות:
   > **הודעה:** מנוע החישוב אינו זמין כעת. אנא ודאו חיבור תקין לאינטרנט ורעננו את הדף.
2. **מניעת הצגת נתונים מזויפים:**
   * לפני שהחישוב רץ או בעת שגיאה, ערכי התוצאות מאופסים לקו מפריד (`—`) וגובה עמודת הערכת השווי מאופס ל-`0%`.
   * כרטיסיית התוצאות מוחשכת קלות (`disabled-dim`).
   * בשום מקרה לא מוצגת תוצאה פיקטיבית כאילו חושבה בהצלחה אם מנוע ה-Python לא פעל.

### ד. כיצד לוודא ש-Python באמת מבצע את החישוב (לבודקים ולמרצים)
למרות שהממשק הפך נקי וידידותי לקהל הרחב, מנגנון האימות הפנימי נשמר במלואו עבור צוות ההוראה:
1. פתחו את המצגת בדפדפן (למשל Microsoft Edge או Chrome).
2. הגיעו לשקופית 14.
3. לחצו על מקש `F12` (או קליק ימני -> "בדוק" / "Inspect") ועברו ללשונית **Console**.
4. הקלידו:
   ```javascript
   verifyPythonExecution()
   ```
   ולחצו `Enter`.
5. תקבלו פלט JSON ישיר המאמת כי:
   * `isPythonRunning: true`
   * `runtime: "Pyodide WebAssembly (Client-side)"`
   * `pythonVersion: "3.11.3"`
   * תוצאת חישוב לדוגמה מתוך המנוע: `executedBy: "Pyodide CPython WebAssembly"`.
6. בנוסף, בכל הזזה של המחוון או לחיצה על הכפתור "בדקו את השפעת המחיר", נרשמת ל-Console רשומת חישוב מפורטת של Python:
   `[Python Calculation Result]: Map { ... }`
