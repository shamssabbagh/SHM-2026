## 2. תיאור הפעולות שבוצעו וההחלטות ההנדסיות

### א. שילוב מנוע Pyodide (Python WebAssembly)
1. **הרצה מקומית בדפדפן:** נעשה שימוש בספריית `pyodide.js` המאפשרת להריץ סביבת פייתון מלאה (CPython המהודר ל-WebAssembly) ישירות בקליינט ללא צורך בשרת אחורי.
2. **ניהול מחזור חיים וטיפול בשגיאות (Failure Transparency):**
   * כל עוד מנוע ה-Python בטעינה, מוצג סטטוס `⏳ טוען מנוע Python (Pyodide WASM)...`.
   * במידה וטעינת Pyodide נכשלת (למשל בהיעדר חיבור אינטרנט לטעינת ה-WASM), מוצגת הודעת שגיאה ברורה: `⚠️ מנוע Python אינו זמין. החישוב לא בוצע.` ואזור התוצאות ננעל – לא מוצגות תוצאות מזויפות.
   * כאשר המנוע נטען בהצלחה, מופקת גרסת ה-Python הרשמית (`sys.version`) ומאושרת מוכנות המערכת.

### ב. מימוש הסימולציה לפי הנוסחה וההסתייגות המדעית
1. **מוצר לדוגמה:** אוזניות סטודיו שמחיר הבסיס שלהן הוא **399 ₪**.
2. **מחוון מחיר עוגן:** סליידר בטווח של **400 ₪ עד 1,200 ₪** המאפשר למשתמש לבחור כל עוגן מחיר.
3. **קוד פייתון אמיתי:**
   ```python
   def calculate_anchoring(base_price, anchor_price):
       # נוסחה להמחשה לימודית בלבד (אינה מודל מאומת):
       estimated_val = base_price + 0.3 * (anchor_price - base_price)
       diff = estimated_val - base_price
       pct_increase = (diff / base_price) * 100
       return {
           "estimated_value": round(estimated_val, 2),
           "difference": round(diff, 2),
           "pct_increase": round(pct_increase, 1),
           "anchor_price": anchor_price,
           "base_price": base_price
       }
   ```
4. **הסתייגות מדעית בולטת:** צוין במפורש בראש השקופית ובכרטיסיית הסימולציה כי הנוסחה ומקדם $0.3$ נבחרו לצורך המחשה והדגמה בלבד ואינם מהווים מודל פסיכולוגי מאומת.

### ג. תצוגה חזותית ואינטראקטיבית
* **גרף עמודות דינמי:** מציג השוואה חזותית ברורה בין:
  1. מחיר הבסיס (399 ₪)
  2. מחיר העוגן שהמשתמש בחר (400–1,200 ₪)
  3. הערכת השווי המושפעת שחושבה ע"י Python
* **כרטיסיות מדדים:** הצגת הערכת השווי המדויקת, תוספת השווי בשקלים והאחוז הנגזר מעוצמת העוגן.
* **תיבת קוד Python פתוחה:** הצגת קוד הפייתון המלא שמבצע את החישוב לעיון המשתמשים.
