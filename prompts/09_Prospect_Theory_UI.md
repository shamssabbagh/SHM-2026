## 2. תיאור הפעולות שבוצעו וההחלטות ההנדסיות

### א. מבנה השקופית והתאמה לשפת העיצוב
1. **כותרת ותווית עליונה:**
   * כותרת ראשית: **"תורת הסיכויים: למה הפסד כואב יותר מרווח?"**
   * כותרת משנה באנגלית: <bdi>`Prospect Theory: Why Losses Feel Stronger Than Gains`</bdi>
   * תגית סוג תוכן: `סימולציה אינטראקטיבית`
   * תיבת הסבר עליונה: *"תורת הסיכויים של כהנמן וטברסקי מראה שאנשים אינם מגיבים באופן סימטרי לרווחים ולהפסדים – הפסד נתפס חזק וכואב יותר מרווח באותו גודל."*
2. **פריסת גריד דו-עמודית הרמונית:**
   * הגריד תוכנן בזהות מלאה לשקופית 14 הסמוכה (`.prospect-simulation-grid`), עם יחס של 1:1.15 המאזן בין עמודת השליטה והחוויה לעמודת הגרף הוויזואלי.

### ב. עמודת השליטה והחוויה הפסיכולוגית
1. **מתג בחירה בין רווח להפסד (Segmented Toggle):**
   * כפתור **"▲ רווח כספי"** הזוהר בירוק-טורקיז (`active-gain`).
   * כפתור **"▼ הפסד כספי"** הזוהר בורוד-אדום (`active-loss`).
2. **מחוון סכום רציף (0 עד 500 ₪):**
   * תגית סכום גדולה ובולטת המתעדכנת מיידית: `+ ₪ 200` או `- ₪ 200`.
   * שנתות סימון: `₪ 0`, `₪ 250`, `₪ 500`.
3. **כרטיס תוצאה מרכזי – החוויה הפסיכולוגית המשוערת:**
   * **אייקונים רגשיים וצרכניים דינמיים:**
     * ברווח: מטבעות וסל קניות (🪙 / 🛍️) יחד עם חיוך משתנה (😊 / 🤩).
     * בהפסד: ארנק ושטרות עפים (👛 / 💸) יחד עם הבעה מודאגת (😟 / 😫).
   * **מסר פסיכולוגי:**
     * ברווח: *"הרווח נתפס כחיובי, אך בעוצמה מתונה יחסית"*
     * בהפסד: *"ההפסד נתפס בעוצמה רגשית גבוהה יותר מאשר רווח מקביל"*
4. **השוואה ויזואלית: סכום אמיתי מול עוצמה פסיכולוגית:**
   * **סרגל סכום אמיתי (אפור-כסוף):** משקף את הערך הכספי הריאלי ($x$).
   * **סרגל עוצמה פסיכולוגית:**
     * עבור רווח של 200 ₪: ערך סובייקטיבי מתון (~105 נקודות ערך, רוחב סרגל קצר, תגית `עוצמה מתונה 1.0x`).
     * עבור הפסד של 200 ₪: עוצמת כאב כפולה (~237 נקודות כאב, רוחב סרגל כפול, תגית `עוצמה כפולה פי ~2.25!`).
5. **תיבת תובנה פסיכולוגית מודגשת:**
   > 💡 **תובנה פסיכולוגית:** צרכנים מגיבים חזק יותר לאפשרות של הפסד מאשר לאפשרות של רווח באותו גודל. לכן מסרים שיווקיים רבים מדגישים מה נפסיד אם לא נקנה, ולא רק מה נרוויח אם כן.

### ג. עמודת הגרף האינטראקטיבי – עקומת S א-סימטרית
1. **גרף SVG וקטורי חד ומדויק אקדמית:**
   * ציר X: הפסדים $\leftarrow$ נקודת ייחוס (0) $\rightarrow$ רווחים.
   * ציר Y: כאב פסיכולוגי $\leftarrow$ 0 $\rightarrow$ הנאה וערך חיובי.
2. **א-סימטריה מתמטית בשיפוע:**
   * פונקציית הרווחים ($x \ge 0$): $v(x) = x^{0.88}$ (קעורה ובעלת שיפוע מתון).
   * פונקציית ההפסדים ($x < 0$): $v(x) = -2.25 \times (-x)^{0.88}$ (קמורה ובעלת שיפוע תלול פי 2.25).
3. **נקודה פעילה נעה (Live Animated Marker):**
   * בהזזת הסליידר או בלחיצה על רווח/הפסד, נקודה זוהרת נעה בדיוק לאורך העקומה המתמטית.
   * קווי עזר מקווקוים (`guide lines`) מחברים את הנקודה לציר ה-X ולציר ה-Y.
   * Tooltip מרחף מציג את הסכום הנבחר מעל הנקודה.
4. **סרגל נתונים תחתון:**
   * מציג את הסכום, הערך הפסיכולוגי הסובייקטיבי, ויחס הכאב/עונג.

### ד. מנוע Python ברקע (Pyodide WebAssembly)
* **אפס חשיפה של קוד לקהל:** אין שום בלוק קוד, אין שמות פרמטרים טכניים (`lambda`, `alpha`, `def`) בשקופית.
* **קוד Python רשמי בקליינט:** בתוך `js/python_runner.js` הוטמעה פונקציית Python מלאה:
  ```python
  def calculate_prospect_theory(amount, is_loss):
      x = float(amount)
      if is_loss:
          val = -2.25 * (x ** 0.88) if x > 0 else 0.0
          intensity = 2.25 * (x ** 0.88) if x > 0 else 0.0
          ratio = 2.25
          message = "ההפסד נתפס בעוצמה רגשית גבוהה יותר מאשר רווח מקביל"
      else:
          val = (x ** 0.88) if x > 0 else 0.0
          intensity = val
          ratio = 1.0
          message = "הרווח נתפס כחיובי, אך בעוצמה מתונה יחסית"
      return { ... }
  ```
* **אימות ישיר לבודקים ומרצים:** פונקציית `verifyPythonExecution()` בקונסול הדפדפן מחזירה כעת אימות חי הן עבור שקופית 13 והן עבור שקופית 14!
