## התקדמות הפרויקט (Project Progress)

### שלב 1 - הגדרת מאגר GitHub
- יצירת המאגר `SHM-2026`.
- חיבור מרצה ושותפה לצוות.
- חיבור ל-GitHub Desktop.

### שלב 2 - אפיון דרישות מוצר (PRD) ותשתית מצגת
- יצירת מסמך `PRD.md` מפורט הכולל סילבוס של 19 שקופיות.
- פיתוח שלד ראשוני ב-HTML, CSS ו-JavaScript.
- תמיכה מלאה בכיווניות עברית (RTL) ובשילוב מונחים באנגלית (BIDI).
- הקמת תיקיית `prompts/` לתיעוד מסודר של הפרומפטים ששימשו בפיתוח.

### שלב 3 - שדרוג חזותי ושילוב מדיה
- עדכון שקופית הפתיחה: שילוב תמונת Hero של המוח הצרכני ועדכון פרטי הצוות באופן שוויוני ומקצועי.
- הוספת דיאגרמות תהליכיות ואיורים מבוססי תוכן בתיקיית `assets/images/`.
- הבטחת טעינה מקומית חלקה של כל הנכסים בעת פתיחה ישירה מקובץ (`file:///`).

### שלב 4 - פיתוח רכיב תלת-ממדי אינטראקטיבי (Three.js) בשקופית 8
- החלפת ה-Placeholder בשקופית 8 במודל מוח תלת-ממדי מבוסס חלקיקים ורשת קשרים (`js/brain3d.js`).
- ספריית Three.js מאוחסנת מקומית (`js/vendor/three.min.js`) לפעולה מלאה ללא תלות ברשת (Offline-ready).
- סיבוב חופשי 360 מעלות באמצעות העכבר והמגע, עם כפתורי הפעלה/עצירת סיבוב ואיפוס מבט.
- הדגשת 4 אזורים קונספטואליים (PFC, אמיגדלה, אינסולה, ו-NAcc) בליווי כרטיסיית הסברים אינטראקטיבית בעברית.

### שלב 5 - שדרוג והרחבת מערכת הצלילים (Web Audio API Synthesizer)
- פיתוח מנוע אודיו ייעודי ועצמאי (`js/audio.js`) המבוסס 100% על סינתזה של **Web Audio API** (ללא קובצי סאונד חיצוניים וללא בעיות רישוי).
- **צליל רקע עתידני מתמשך (Ambient Drone):** סינתוז הרמוני חי של גלי קול רכים ומתנד LFO המדמה "נשימה" נוירונלית רגועה בשקופית 8.
- **הפעלה יזומה בלבד:** צליל הרקע מתחיל אך ורק לאחר לחיצה יזומה של המשתמש על כפתור השמע.
- **אפקטים קוליים (Chimes):** צלילי תהודה קצרים בהקלקה על כל אחד מארבעת האזורים המוחיים.
- **בקרת שמע מרכזית (Master Mute & Volume):**
  - כפתור **Mute / Unmute** המשתיק מיידית הן את צליל הרקע והן את האפקטים הקוליים.
  - סליידר שליטה בעוצמת הקול (0% עד 100%) עם חיווי אחוזים דינמי.
- **עצירה אוטומטית במעבר שקופיות:** צליל הרקע עוצר ודועך מיד בעת מעבר לשקופית אחרת, ומתחדש בעת חזרה לשקופית 8 (אם אושר שמע).
- **מניעת שכפול צלילים (Singleton):** מנגנון ניקוי מתנדים מובנה המונע ריבוי צלילי רקע במקביל.
- **תאימות מלאה לדפדפן Microsoft Edge ול-Chrome.**
