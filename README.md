### שלב 5 - שדרוג מוזיקת רקע עתידנית ושליטה נפרדת בעוצמות (Web Audio API)
- פיתוח מנוע אודיו מורחב (`js/audio.js`) המבוסס 100% על סינתזה של **Web Audio API** (ללא קובצי סאונד חיצוניים, ללא בעיות רישוי ותואם לחלוטין לדפדפן Microsoft Edge).
- **מוזיקת רקע Ambient עשירה ומלודית:**
  - משטח הרמוני חם (Warm Ethereal Pad) בתדרי $A2, E3, A3, C4$ עם אפקט מקהלה רך ומסנן נשימה דינמי.
  - מנגינה קריסטלית מעגלית מרגיעה (Generative Arpeggio) בסולם A-Minor פנטטוני עם מעגל Delay מרחבי.
- **הפעלה יזומה בלבד:** מוזיקת הרקע מתחילה אך ורק לאחר לחיצה יזומה על כפתור השמע.
- **איזון עוצמות מקצועי:** מוזיקת הרקע נשמעת בעוצמה ברורה ונעימה, והאפקטים הקוליים של בחירת אזור מוחי מודגשים ומובחנים מעליה.
- **שליטה נפרדת בעוצמות:**
  - כפתור **Mute / Unmute** המשתיק מיידית הן את מוזיקת הרקע והן את האפקטים.
  - סליידר ייעודי לשליטה בעוצמת מוזיקת הרקע (0% עד 100%).
  - סליידר ייעודי לשליטה בעוצמת אפקטי האזורים המוחיים (0% עד 100%).
- **עצירה אוטומטית במעבר שקופיות:** המוזיקה והאפקטים נפסקים מיידית ודועכים ברכות בעת מעבר לכל שקופית אחרת, ומתחדשים בחזרה לשקופית 8 (אם אושר שמע).
- **מניעת שכפול צלילים (Singleton):** מנגנון ניקוי מתנדים המבטיח שלעולם לא יתנגנו שני מופעי מוזיקה במקביל.

### שלב 6 - סימולציית אפקט העיגון ומנוע הרצת Python בדפדפן (Pyodide WebAssembly)
- שילוב מנוע חישוב Python מלא בקליינט (`js/python_runner.js`) באמצעות Pyodide WebAssembly בשקופית 14.
- הצגת מוצר עוגן לדוגמה (אוזניות שמחיר הבסיס שלהן הוא 399 ₪) ומחוון לשינוי מחיר עוגן (400 ₪ עד 1,200 ₪).
- הרצת נוסחת המחשה לימודית: $\text{Valuation} = 399 + 0.3 \times (\text{Anchor} - 399)$ ישירות בקוד Python.
- הצגת הסתייגות מדעית בולטת כי הנוסחה ומקדם 0.3 נבחרו לצורך הדגמה בלבד ואינם מודל פסיכולוגי מאומת.
- תצוגה חזותית דינמית הכוללת מדדי תוספת שווי וגרף עמודות השוואתי בזמן אמת.

## כיצד לוודא ש-Python באמת מבצע את החישוב (לבדיקת מרצים ובודקים)
על אף שהממשק החיצוני נקי לחלוטין מפרטים טכניים ומותאם לקהל הרחב, מנגנון האימות נגיש ישירות מתוך הדפדפן:
1. פתחו את `index.html` בדפדפן (Chrome / Edge / Firefox).
2. נווטו לשקופית 14 ("אפקט העיגון: איך המחיר הראשון משפיע עלינו?").
3. פתחו את כלי המפתחים בלחיצה על מקש `F12` (או `Ctrl + Shift + I`) ועברו ללשונית **Console**.
4. הריצו את הפקודה:
   ```javascript
   verifyPythonExecution()
   ```
5. יוצג אובייקט JSON המאמת כי:
   - `isPythonRunning: true`
   - `runtime: "Pyodide WebAssembly (Client-side)"`
   - `pythonVersion: "3.11.3"`
   - `testCalculation: { formula: "399 + 0.3 * (850 - 399)", result: 534.3, executedBy: "Pyodide CPython WebAssembly" }`
6. בנוסף, בכל שינוי מחוון או לחיצה על כפתור "בדקו את השפעת המחיר", נרשמת ל-Console תוצאת חישוב ישירה של Python.
